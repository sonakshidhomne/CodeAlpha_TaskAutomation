# JPG File Organizer Using Python

## Project Description
This project is a Python-based task automation tool that automatically organizes JPG images into a separate folder.

## Features
- Automatically identifies JPG files.
- Creates a destination folder if it does not exist.
- Moves JPG images from the source folder.
- Displays the total number of files moved.

## Technologies Used
- Python
- OS Module
- Shutil Module

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Run the following command:

```bash
python organizer.py
```

## Expected Output
```text
File Organization Completed!
Total JPG files moved: 3
```
